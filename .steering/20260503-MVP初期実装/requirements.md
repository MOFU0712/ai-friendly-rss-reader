# 要件定義 — MVP初期実装

## 背景・目的

RSSフィードを快適に消費するための軽量Webアプリケーション。
「気になった記事をまとめてAIに渡す」ワークフローを中心に設計する。

詳細: `docs/product-requirements.md`

---

## 対象スコープ（MVP）

| 機能 | 概要 |
|------|------|
| RSSフィード管理 | フィードURLの登録・削除・一覧表示 |
| 記事カード表示 | タイトル・概要・サイト名・公開日時をカード形式で表示 |
| 既読管理 | 記事クリックで既読化、デフォルト非表示・トグル切替 |
| 複数選択 | チェックボックスで複数記事を選択 |
| Markdown出力 | 選択記事を `- [タイトル](URL)` 形式でクリップボードにコピー |
| フィード自動更新 | Cron Triggerで1時間に1回フィードを取得・DB保存 |
| お気に入り優先表示 | お気に入りフィードの記事を上部セクションに表示 |

---

## 機能要件

### フィード管理
- RSSフィードURLを登録できる（タイトル自動取得）
- 登録済みフィードの一覧を確認できる
- フィードを削除できる（確認ダイアログあり）
- フィードをお気に入り設定できる（★トグル）

### 記事表示
- タイトル・概要テキスト・サイト名・公開日時をカード形式で表示
- お気に入りフィードの記事は上部にグループ表示
- 各セクション内は `published_at` 降順
- 既読記事はデフォルト非表示（トグルで表示切替可）
- 記事タイトルクリックで元記事URLを新タブで開く（同時に既読マーク）

### 記事選択とMarkdown出力
- チェックボックスで複数記事を選択
- 1件以上選択時に画面下部にコピーバーを表示
- コピーボタンで選択記事を Markdown 形式でクリップボードに書き出し
- コピー成功後にトースト通知を表示

### フィード更新
- Cron Triggerで1時間に1回、全フィードを取得・パース
- 記事の重複は GUID（またはURL）で排除
- 取得エラー時はスキップし、正常なフィードのみ保存

---

## 非機能要件

| 項目 | 要件 |
|------|------|
| フィード更新頻度 | 1時間に1回（Cloudflare Cron Trigger `0 * * * *`） |
| ホスティング | Cloudflare Pages（無料枠） |
| DB | Cloudflare D1（SQLite互換、無料枠） |
| 言語 | TypeScript（フロントエンド・バックエンド統一） |
| 対応デバイス | デスクトップ優先、モバイル対応（レスポンシブ） |
| 認証 | MVP段階では不要（1ユーザー想定） |
| コスト | 無料枠内に収める |
